## 🎯 Objective
This repository contains my SQL codes, queries, and data analysis projects. I am building a strong foundation in database management, data extraction, and relational data manipulation to extract actionable business insights from raw datasets.

## 🛠️ Skills & Concepts Covered
Throughout the projects and practice files in this repository, I am implementing the following SQL concepts:
* **Basic Queries:** `SELECT`, `WHERE`, `ORDER BY`, `GROUP BY`, `HAVING`
* **Data Manipulation (DML):** `INSERT`, `UPDATE`, `DELETE`
* **Data Definition (DDL):** `CREATE`, `ALTER`, `DROP`
* **Relational Database Concepts:** `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, `FULL OUTER JOIN`
* **Advanced Functions (Upcoming):** Window Functions, CTEs (Common Table Expressions), and Subqueries
